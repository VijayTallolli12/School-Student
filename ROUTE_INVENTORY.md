## Full Route Inventory

Canonical route = the URL path you can navigate to in Expo Router v6.
A directory `index.tsx` registers as the directory path (e.g. `transport/index.tsx` → `/transport`).
The literal `/<dir>/index` is **not** a valid route in Expo Router v6.
