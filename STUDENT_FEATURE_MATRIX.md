# STUDENT_FEATURE_MATRIX

Date: 2026-08-06

| Feature | Decision | Reason |
|---|---|---|
| Dashboard | Keep + Redesign | Daily student context is essential |
| Attendance | Keep | Core academic discipline tracking |
| Homework | Keep | Daily action item |
| Assignments | Keep (pending merge decision) | May represent separate workflow from homework |
| Timetable | Keep | High daily value |
| Subjects | Merge into Academics | No dedicated standalone screen currently |
| Teachers | Merge into Timetable/Subject context | Not a standalone high-frequency flow |
| Fees | Keep | Important but lower-frequency than academics |
| Exams | Keep | Upcoming planning essential |
| Results | Keep | Performance feedback loop |
| Circulars | Keep | School communication |
| Notifications | Keep | Urgent alerts and reminders |
| Documents / Study Materials | Keep + Reframe | Student resource access |
| Downloads | Merge into Documents | Avoid duplicate module |
| Calendar | Keep | Events and holidays |
| Leave Requests | Keep | Student self-service |
| Library | Keep if enabled | School-dependent module |
| Transport | Keep if enabled | School-dependent module |
| Support | Keep under Profile/Settings | Lower-frequency utility |
| Settings | Keep | Account and app controls |
| Profile | Keep | Identity and account details |

## Homework vs Assignments
- Current recommendation: Keep both but clearly label intent.
- Merge only if backend business rules confirm they are the same workflow.
